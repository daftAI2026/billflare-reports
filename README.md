# billflare-reports

Public intake for source-linked reports about Cloudflare billing. Submitting a report creates a public issue. A report is not verified by this form and is not automatically added to Billflare.

## Submit a report

- [English report form](https://github.com/daftAI2026/billflare-reports/issues/new?template=report-en.yml)
- [中文报告表单](https://github.com/daftAI2026/billflare-reports/issues/new?template=report-zh.yml)

## Public review

Every issue is public. The `pending-review` label means that maintainers have not finished reviewing its sources. A user-supplied alias is optional and does not verify identity.

Provide a public HTTPS source and a factual summary. Add public links for later updates when available. Keep the original currency and billing period. Do not present an allegation as a verified fact.

Do not submit passwords, API keys, tokens, account identifiers, private billing pages, private messages, payment details, email addresses, or unredacted screenshots. Do not add scripts, HTML, embedded images, `@mentions`, or private links. Treat every field and link as public.

# billflare-reports（中文）

本仓库收集有公开来源的 Cloudflare 账单报告。提交后会创建公开 Issue。表单不会核验事实，也不会自动将报告收录到 Billflare。

## 提交报告

- [English report form](https://github.com/daftAI2026/billflare-reports/issues/new?template=report-en.yml)
- [中文报告表单](https://github.com/daftAI2026/billflare-reports/issues/new?template=report-zh.yml)

## 公开审核

每个 Issue 都公开可见。`pending-review` 表示维护者尚未完成来源审核。报告人可填写别名；别名不会验证身份。

请提供公开 HTTPS 来源和事实摘要。后续进展请附公开来源。保留原币种和账期。不要把指控写成已核实事实。

请勿提交密码、API Key、令牌、账号标识、私人账单页面、私信、支付信息、邮箱或未打码截图。请勿添加脚本、HTML、嵌入图片、`@提及` 或私人链接。所有字段和链接都会公开。
